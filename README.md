# Void Pointer with memset()

## Author
M.Likitha

## Description
This program demonstrates using a void pointer with
the memset() function.

The void pointer points to a character array, and
memset() replaces the first five characters with '*'.

## Concepts Used
- Void pointer
- memset()
- Character array
- Memory manipulation
- Pointer assignment

## How to Run

gcc void_pointer_memset.c -o void_pointer_memset

./void_pointer_memset
